When you publish a plan, Kinde syncs the plan’s features and charges for billing and creates a **plan version** that new customers can buy.

We recommend testing, reviewing, and making all changes in a **draft** before you publish.

## Publish your first version

1. Go to **Billing → Plans** and open your plan (or select **Add plan** if you have not created one yet).
2. Configure charges, features, and plan settings.
3. When you are ready, select **Publish plan** in the top right.
4. Review the confirmation message. It shows which **version** will be created (starting at **v1**) and, if the plan is on one or more pricing tables, which tables will start selling that version to new sign-ups.
5. Select **Publish**.

Repeat for each plan you want customers to subscribe to.

## Publish a new version of an existing plan

When a plan already has subscribers, use **versioning** instead of editing the live catalog in place:

1. Open the plan and go to the **Versions** tab (or select **View versions** from the plans list).
2. Edit the current **draft** if you already have one. If you need a fresh copy from a published version, open that version and select **Save as draft**. If an unpublished draft already exists, **Save as draft** replaces it and discards its changes — confirm in the dialog before you continue.
3. Change charges, features, or settings in the draft.
4. Select **Publish plan** and confirm. Kinde creates the next version (for example **v2**).

Existing subscribers stay on the version they joined. New subscribers—including self-serve sign-ups through pricing tables—get the latest published version.

Learn more about drafts, versions, and what you can edit on each: [About plans — Draft and published plans, and plan versioning](/billing/manage-plans/about-plans/#draft-and-published-plans-and-plan-versioning).
