This topic explains how to customize billing flows with Kinde, including URL parameters, direct auth URLs, and SDK usage in React.

Examples are given in React, but can be adapted for most frameworks.

## Edit the auth URL parameters directly

Here’s a standard Kinde auth URL:

```

https://<your_kinde_subdomain>.kinde.com/oauth2/auth
  ?response_type=code
  &client_id=<your_kinde_client_id>
  &redirect_uri=<your_app_redirect_url>
  &scope=openid%20profile%20email
  &state=abc

```

Add these parameters as needed:

| Parameter | Description |
| --- | --- |
| `plan_interest` | Pre-selects a plan by its key and skips the plan selection screen |
| `pricing_table_key` | Displays a specific live pricing table during sign-up |
| `is_create_org` | Triggers the organization (B2B) sign-up flow (`is_create_org=true`). Requires a role with **Assign to the creator** and the `org:write:billing` system permission so the creator can subscribe the new organization to a plan |

### Examples

- Pre-select a plan:
    
    ```
    ...&plan_interest=pro_monthly
    ```
    
- Show a specific pricing table:
    
    ```
    ...&pricing_table_key=spring_promo
    ```
    
- Organization (B2B) sign-up with a pricing table:

    ```
    ...&is_create_org=true&pricing_table_key=pricing_table_schools&prompt=create
    ```

<Aside type="warning" title="Important">
When combining `is_create_org=true` with billing (`pricing_table_key`, `plan_interest`, or a default organization pricing table), the user creating the organization must be automatically assigned a role that includes the `org:write:billing` system permission (and `org:read:billing` to view billing in the self-serve portal). If no role has **Assign to the creator** and `org:write:billing` enabled in **Settings > Roles**, Kinde will create the organization and user but skip the pricing table and billing steps. See [Step 1: Add billing role (B2B)](/billing/get-started/add-billing-role/).
</Aside>

## Integrate billing using the React SDK

You can avoid manual URL construction by using our SDK components. Here's how.

**User sign-up (default):**

```jsx
<RegisterLink>Sign up</RegisterLink>
```

**Org sign-up (B2B):**

```jsx
<RegisterLink isCreateOrg>Sign up your organization</RegisterLink>
```

**Pre-select a user plan:**

```jsx
<RegisterLink planInterest="pro_monthly">Sign up with Pro plan</RegisterLink>
```

**Show a specific pricing table:**

```jsx
<RegisterLink pricingTableKey="spring_promo">Spring Promo Sign up</RegisterLink>
```

**Combine for B2B + pricing table:**

```jsx
<RegisterLink isCreateOrg pricingTableKey="enterprise_2024">
  Sign up your company
</RegisterLink>
```
