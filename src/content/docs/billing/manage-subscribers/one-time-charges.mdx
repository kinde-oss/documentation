One-time charges are optional single purchases on a subscription plan; for example AI credit packs, storage top-ups, or feature unlocks. You configure them on the plan; customers buy them after they subscribe, or you assign them from the admin.

## What you need

- One-time charges are configured per plan. See [Add one-time charges section](/billing/manage-plans/create-plans/#add-one-time-charges-to-a-plan) in the Create billing plans guide.
- Customers need a saved payment method to buy from the portal, unless you assign a complimentary purchase from the admin.
- Purchases attach to the customer’s **current billing agreement**. They do not survive a plan change or cancellation.

## What customers can buy

Each one-time charge on a plan can be:

| Setting | Options |
| --- | --- |
| Usage | **Unmetered** (access only) or **Metered** (track consumption against purchased units) |
| Pricing | **Flat** (fixed price per purchase) or **Package** (price per set number of units) |
| Expiry | **Never expires** or **Expires with the billing cycle** |

On the plan details page, purchased items show units granted, amount paid, expiry, and current usage for metered charges.

## Buy from the self-serve portal

Authorized customers can buy one-time charges from the portal **Plan** page.

1. Enable the self-serve portal and plan management. See [Self-serve portal for users](/build/self-service-portal/self-serve-portal-for-users/) or [Self-serve portal for organizations](/build/self-service-portal/self-serve-portal-for-orgs/).
2. Ensure the customer has billing write permission (`write:billing` for B2C users, `org:write:billing` for B2B organization members).
3. The customer opens the portal and goes to **Plan**.
4. In **One-time purchases**, they select **Purchase** or **Buy more**.
5. For package-priced charges, they choose how many packages to buy, then confirm payment.

If no payment method is on file, the customer is prompted to add one before checkout completes.

## Assign from the Kinde admin

You can grant a one-time purchase without the customer going through the portal:

1. Open the user or organization and select **Billing**.
2. In **One-time purchases** section, select **Assign** or **Assign more**.

    ![assign one-time purchase from the Kinde admin](https://imagedelivery.net/skPPZTHzSlcslvHjesZQcQ/bd46fa05-179a-4fbd-e0f8-f79421be8500/socialsharingimage)

3. For package-priced charges, enter the number of packages.
4. Choose:
    - **Charge default payment method** — invoices and charges the customer’s saved card
    - **Assign without charge** — grants the purchase at no cost

<Aside>

You need permission to create billing agreements.

</Aside>

## Metered one-time charges

When a one-time charge is **metered**, purchased units set the allowance. Record consumption via the Management API after the first purchase completes.

- **Never expires** — usage is tracked as a lifetime total for that agreement and feature.
- **Expires with the billing cycle** — usage resets each billing cycle, like recurring metered features.

See [Add metered usage for a customer via API](/billing/manage-subscribers/add-metered-usage/).

## Plan changes and cancellations

One-time purchases belong to the current billing agreement.

| Event | What happens |
| --- | --- |
| Customer changes plan | Active one-time purchases on the old agreement are forfeited. Kinde lists them in the confirmation dialog. No refund is issued. |
| Customer cancels | The same forfeiture rules apply. The cancel dialog warns when active purchases exist. |
| Customer buys again on a new plan | Treated as a new purchase. Prior payment is not credited. |

See [Subscription upgrade and downgrade methods](/billing/manage-subscribers/upgrade-downgrade-methods/#one-time-purchases-when-changing-plan) and [Cancel a subscription](/billing/manage-plans/cancel-plans/#one-time-purchases-when-cancelling).

## Management API

API reference for these endpoints is generated from the OpenAPI spec:

| Endpoint | Purpose |
| --- | --- |
| [`GET /api/v1/billing/one_time_purchases`](https://docs.kinde.com/kinde-apis/management/#tag/billing-one-time-purchases/get/api/v1/billing/one_time_purchases/) | List current paid, non-expired purchases for a customer |
| [`GET /api/v1/billing/meter_usage`](https://docs.kinde.com/kinde-apis/management/#tag/billing-meter-usage/get/api/v1/billing/meter_usage/) | Page usage records and read the grant snapshot |
| [`POST /api/v1/billing/meter_usage`](https://docs.kinde.com/kinde-apis/management/#tag/billing-meter-usage/post/api/v1/billing/meter_usage/) | Record usage, including metered one-time features after the first purchase |

Enable the `read:billing_one_time_purchases`, `read:meter_usage`, and `create:meter_usage` scopes on your M2M application as needed.

## Deleting plans with one-time purchases

You cannot delete a plan while customer one-time purchase records still reference a published plan version on that plan. Remove or migrate customers first.
