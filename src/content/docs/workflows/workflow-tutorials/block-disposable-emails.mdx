<Aside>

Kinde can block known disposable email providers out of the box. See how to [enabled this setting](/build/set-up-options/block-disposable-emails/) from the Kinde dashboard. Use this workflow when you also want to block domains that are not on that list.

</Aside>

The workflow runs on the `user:pre_registration` trigger and checks the sign-up email against your own list.

## What you need

- A [Kinde](https://app.kinde.com/register) account (Sign up for free)
- A workflow Git repository connected to your Kinde account (follow the [quick start guide](/workflows/getting-started/quick-start-guide/))
- Your own list of prohibited email domains

## Block disposable emails

### Set up the environment variable

1. Create a new environment variable in **Settings > Data management > Env variables** called `DISPOSABLE_EMAIL_DOMAINS`. 
2. Use a comma-separated list, for example `yopmail.com,guerrillamail.com,mailinator.com`.

### Workflow logic

1. Read the email from the pre-registration event:

    ```typescript
    event.context.user.email
    ```

2. Read your domain list from your environment variable (e.g., `DISPOSABLE_EMAIL_DOMAINS`):

    ```typescript
    const disposableEmailDomains = getEnvironmentVariable(
      "DISPOSABLE_EMAIL_DOMAINS"
    )?.value
    ```

3. Display a message on the Kinde form when registration is blocked using the `denyAccess` built-in function:

    ```typescript
    denyAccess("Disposable email domain detected")
    ```

### Full `Workflow.ts` file example

```typescript
import {
  onUserPreRegistrationEvent,
  WorkflowSettings,
  WorkflowTrigger,
  denyAccess,
  getEnvironmentVariable,
} from "@kinde/infrastructure";

// The settings for this workflow
export const workflowSettings: WorkflowSettings = {
  id: "preRegistration",
  name: "Block disposable emails",
  failurePolicy: {
    action: "stop",
  },
  trigger: "user:pre_registration",
  bindings: {
    "kinde.env": {},
    "kinde.auth": {},
  },
};

// The workflow code to be executed when the event is triggered
export default async function Workflow(
  event: onUserPreRegistrationEvent
) {
  console.log("handlePreRegistration", event);

  // Check if user email exists in the event
  if (!event.context.user.email) {
    console.log(
      "No user email found in pre-registration event, allowing registration"
    );
    return;
  }

  const disposableEmailDomains = getEnvironmentVariable(
    "DISPOSABLE_EMAIL_DOMAINS"
  )?.value;

  // If no disposable email domains are configured, allow registration
  if (!disposableEmailDomains) {
    console.log(
      "No disposable email domains configured, allowing registration"
    );
    return;
  }

  const disposableEmailDomainsArray = disposableEmailDomains
    .split(",")
    .map((domain) => domain.trim());

  const userEmailDomain = event.context.user.email.split("@")[1];

  if (disposableEmailDomainsArray.includes(userEmailDomain)) {
    console.log(
      `Blocking registration for disposable email domain: ${userEmailDomain}`
    );
    denyAccess("Disposable email domain detected");
  } else {
    console.log(`Allowing registration for email domain: ${userEmailDomain}`);
  }
}
```

The workflow checks the sign-up email against the domains in `DISPOSABLE_EMAIL_DOMAINS`:

- If the event has no email, registration continues.
- If the environment variable is not set, registration continues.
- If the domain matches a listed domain, `denyAccess` stops registration and the user sees `Disposable email domain detected`.

### Required bindings

- `kinde.env`: required to read the environment variable
- `kinde.auth`: required for `denyAccess` on the pre-registration trigger

### Test the workflow

1. Attempt to sign up with an email address whose domain is in `DISPOSABLE_EMAIL_DOMAINS`. Registration will be blocked and the user sees `Disposable email domain detected`.
2. Attempt to sign up with an email address whose domain is not in the list. Registration will continue.
