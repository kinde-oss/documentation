You can configure Kinde to send emails using your Groundmail account. This means your users will receive sign-in emails, one-time passcodes, and password reset codes from your business’s email address, and not Kinde’s. Each email also appears in your Groundmail email log with its delivery status.

Please review the documentation at [Customize email sender](/get-started/connect/customize-email-sender/) for details about how custom SMTP works with Kinde and third party providers.

## Create an SMTP credential in Groundmail

You'll need an SMTP credential from Groundmail to use as the password for authenticating with its SMTP server.

In the Groundmail dashboard, go to **SMTP**, enter a name such as `Kinde` under **Create credential**, and select **Create SMTP credential**. Copy the password, as it is only shown once.

See Groundmail's [SMTP](https://docs.groundmail.dev/smtp) documentation for more details.

## Verify your domain

Groundmail requires you to verify the domain being used for the emails. See Groundmail's [Domains](https://docs.groundmail.dev/domains) documentation for verifying your domain.

## Add email sender SMTP details

If you are setting this up and your production environment is already live, we recommend testing this in a staging or test environment first.

1. In Kinde, go to **Settings > Environment > Messaging > Email Sender**.
2. Enter a **Sender name**. This is usually your business name, but might be a specific person.
3. Enable the **Use custom sender** switch. The SMTP details section opens.

4. Enter the **Sender email**. This is the address your users will receive emails from and should be on one of the verified domains in your Groundmail account.
5. Enter the SMTP details of your email provider:
   - Server name - `smtp.groundmail.dev`
   - Port - `587` (or `2525` if your network blocks port 587)
   - User - `groundmail`
   - Password - Use the SMTP credential generated from your Groundmail account
6. Select **Send test email**. This sends a test email to the email address you are logged into Kinde with.
7. If the test is successful, select **Save**.
8. If the test is not successful, check the SMTP details (step 5) and try sending a test email again. If this does not work, see the troubleshooting section below.

## Troubleshooting

If sending a test email fails:
- Verify network connectivity to smtp.groundmail.dev. If port 587 is blocked, use port 2525.
- Confirm the user is `groundmail` and the password is the SMTP credential, not a Groundmail API key.
- Confirm the sender email is on a domain verified in Groundmail.
- Check the **Emails** page in the Groundmail dashboard for the delivery status of each message.

For more details, see Groundmail's Kinde guide: https://docs.groundmail.dev/integrations/kinde
