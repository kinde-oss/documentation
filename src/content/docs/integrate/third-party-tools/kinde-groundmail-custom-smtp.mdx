You can configure Kinde to send sign-up, sign-in, one-time passcode (OTP), and password reset emails through Groundmail. Users receive these emails from your business’s email address. Each email also appears in your Groundmail email log with its delivery status.

See [Customize email sender](/get-started/connect/customize-email-sender/) for which emails still come from Kinde, and for alerts, editing, and resetting the sender.

## What you need

- A [Kinde](https://kinde.com/) account (Sign up for free)
- A [Groundmail](https://groundmail.dev/) account (Sign up for free)

## Groundmail configuration

1. In the Groundmail dashboard, go to **SMTP**, enter a name such as `Kinde` under **Create credential**, and select **Create SMTP credential**.
2. Copy the password, as it is only shown once.
3. Groundmail requires you to verify the domain being used for the emails. See Groundmail's [Domains](https://docs.groundmail.dev/domains) documentation for verifying your domain.

    <Aside type="warning">

    Until a payment method is on file, Groundmail only delivers to the email address of your Groundmail account. The Kinde test email can still pass if you're logged into Kinde with that same address, but your users won't receive anything. Add a payment method in Groundmail under **Settings > Billing** before you switch on the custom sender in production. Groundmail's free plan isn't charged.

    </Aside>

## Configure Kinde email sender

1. In Kinde, go to **Settings > Environment > Messaging > Email Sender**.
2. Enter a **Sender name**. This is usually your business name, but might be a specific person.
3. Enable the **Use custom sender** switch. The SMTP details section opens.

    ![Add email sender SMTP details in Kinde](https://imagedelivery.net/skPPZTHzSlcslvHjesZQcQ/263a1128-00ee-4e17-6f23-e019b282aa00/socialsharingimage)

4. Enter the **Sender email**. This is the address your users will receive emails from and should be on one of the verified domains in your Groundmail account.
5. Enter the SMTP details of your email provider:
   - Server name - `smtp.groundmail.dev`
   - Port - `587` (or `2525` if your network blocks port 587)
   - User - `groundmail`
   - Password - Use the SMTP credential generated from your Groundmail account
6. Select **Send test email**. This sends a test email to the email address you are logged into Kinde with.
7. If the test is successful, select **Save**.
8. If the test is not successful, check the SMTP details (step 5) and try sending a test email again. If this does not work, see the troubleshooting section below.

## Troubleshooting

If sending a test email fails:

- Verify network connectivity to `smtp.groundmail.dev`. If port 587 is blocked, use port 2525.
- Confirm the user is `groundmail` and the password is the SMTP credential, not a Groundmail API key.
- Confirm the sender email is on a domain verified in Groundmail.
- If the test email goes to an address other than your Groundmail account email, confirm a payment method is on file in Groundmail.
- Check the **Emails** page in the Groundmail dashboard for the delivery status of each message.

For more details, see Groundmail's [Kinde guide](https://docs.groundmail.dev/integrations/kinde).
