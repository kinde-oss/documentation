You can configure Kinde to send sign-up, sign-in, one-time passcode (OTP), and password reset emails through Resend. Users receive these emails from your business’s email address. Each email also appears in the Resend dashboard with its delivery status.

See [Custom email sender (SMTP)](/get-started/connect/customize-email-sender/) for which emails still come from Kinde, and for alerts, editing, and resetting the sender.

## What you need

- A [Kinde](https://kinde.com/) account (Sign up for free)
- A [Resend](https://resend.com/) account (Sign up for free)

## Resend configuration

1. In the Resend dashboard, go to **API Keys** and select **Create API key**. You can use an existing API key if you already have one. See Resend's [API keys](https://resend.com/docs/dashboard/api-keys/introduction) documentation for more details.
2. Copy the API key, as a new key is only shown once. You use this key as the SMTP password.
3. Resend requires you to verify the domain being used for the emails. See Resend's [Managing domains](https://resend.com/docs/dashboard/domains/introduction) documentation for verifying your domain.

## Configure Kinde email sender

1. In Kinde, go to **Settings > Environment > Messaging > Email Sender**.
2. Enter a **Sender name**. This is usually your business name, but might be a specific person.
3. Enable the **Use custom sender** switch. The SMTP details section opens.

   ![Email Sender page with the Use custom sender switch turned on](https://imagedelivery.net/skPPZTHzSlcslvHjesZQcQ/576b53fa-35d0-4747-dc0d-1fc9f6dda600/socialsharingimage)

4. Enter the **Sender email**. This is the address your users will receive emails from and should be on one of the verified domains in your Resend account.
5. Enter the SMTP details of your email provider:
   - Server address - `smtp.resend.com`
   - Port - `465`
   - Username - `resend`
   - Password - Use the API key generated from your Resend account

   ![SMTP settings fields on the Kinde Email Sender page](https://imagedelivery.net/skPPZTHzSlcslvHjesZQcQ/263a1128-00ee-4e17-6f23-e019b282aa00/socialsharingimage)

6. Select **Send test email**. This sends a test email to the email address you are logged into Kinde with.
7. If the test is successful, select **Save**.
8. If the test is not successful, check the SMTP details (step 5) and try sending a test email again. If this does not work, see the troubleshooting section below.

## Troubleshooting

If sending a test email fails:

- Verify network connectivity to `smtp.resend.com`.
- Confirm the username is `resend`, the port is `465`, and the password is the Resend API key.
- Confirm the sender email is on a domain verified in Resend.
- Review error messages on the Resend dashboard.

For more details, see Resend's [Send emails with SMTP](https://resend.com/docs/send-with-smtp) guide.
