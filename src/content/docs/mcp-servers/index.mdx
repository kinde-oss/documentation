Kinde supports MCP (Model Context Protocol) so AI agents like Cursor, Claude, and VS Code can call tools over a standard protocol.

You can use MCP in two ways:

1. Expose your APIs to AI agents
2. Manage your Kinde account from an AI agent

## MCP connections for your APIs

<Aside>
  MCP connections are currently in beta. [Contact support](https://kinde.com/support) to enable this feature for your account.
</Aside>

MCP connections turn your registered APIs into MCP tools that AI agents call on behalf of your users.

- Each connection gets a unique URL: `https://<your_business>.kinde.com/mcp/<connection-id>`
- Tools come from your API’s OpenAPI spec
- Clients authenticate with a **user API key**; scopes on that key control which tools appear
- Kinde proxies tool calls to your upstream API and records an audit entry

Use MCP connections when you want AI agents to call your product APIs — with auth, scopes, and auditing handled in Kinde.

See [Add a new MCP connection](/mcp-servers/add-mcp-connection/).

## Manage your Kinde account with MCP

The Kinde Management MCP server lets AI assistants such as Claude, ChatGPT, Grok, Cursor and VS Code work with your Kinde account through the [Kinde Management API](/kinde-apis/management/). Ask in plain language to look up users, inspect organizations, review roles and permissions, or make changes, and the assistant calls the API for you. Tools that change or delete data ask you to confirm first.

The server is at your environment's MCP endpoint, `https://YOUR_BUSINESS.kinde.com/mcp`, and an assistant can connect in two ways:

- **Sign in with your Kinde account.** An owner or admin enables AI agent sign-in for the environment and sets an access level for each team role. People then connect by signing in; there is no key to share, and access follows their role. See [Sign in with your Kinde account](/mcp-servers/sign-in-with-your-kinde-account/).
- **Environment API key.** Create a key enabled for the MCP server, choose its scopes, and configure it in the assistant. Everyone using that assistant shares the key. See [Manage Kinde account with AI agents](/mcp-servers/manage-kinde-account-with-ai-agents/).

Setup guides: [Claude](/mcp-servers/connect-claude/), [ChatGPT](/mcp-servers/connect-chatgpt/), [Grok](/mcp-servers/connect-grok/).

## Compare the two options

| | **MCP connections** (your APIs) | **Kinde Management MCP server** |
| --- | --- | --- |
| **Endpoint** | `https://<your_business>.kinde.com/mcp/<connection-id>` | `https://<your_business>.kinde.com/mcp` |
| **Purpose** | Expose **your** API operations as MCP tools | Manage your Kinde account from an AI agent |
| **Auth** | User API key for the authorized API | Sign in with a Kinde account (per-person, scoped by team role), or an MCP-enabled Environment API key |
| **Tools source** | Your OpenAPI spec operations | The Kinde Management API, one tool per operation, covering create, read, update and delete |
| **Where to configure** | **Dashboard > MCP Servers > Connections** | **Dashboard > Settings > Environment > APIs > Kinde Management API > API keys** |
