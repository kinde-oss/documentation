You can add a custom logo in the Kinde-hosted authentication pages.

<img src="https://imagedelivery.net/skPPZTHzSlcslvHjesZQcQ/bc026367-2121-44b0-f7f7-66ec929b9000/socialsharingimage" alt="custom logo in kinde sign in page" width="400px" />

To add the logo do the following:

1. Sign in to your Kinde dashboard and select **Design**.
2. Go to **Global > Brand**.
3. In the **Logo** section, upload your logo for the **Light** and **Dark** modes.
4. Select **Save**. 


**Logo specifications:**

- Maximum logo size: 1MB
- Supported file types: SVG, PNG, JPG, WebP, and AVIF

<Aside>
The logo is immediately visible on the sign-in page. You do not need to redeploy your application.
</Aside>

Logos are resized to a maximum width or height of 120 pixels based on aspect ratio. SVG works best because it displays well on any screen, but PNG and other formats are accepted.

<Aside type="warning" title="120px is the maximum logo height or width">

The 120 px maximum height or width is a fixed constraint and cannot be changed through standard brand settings. If you need a larger logo, use [custom authentication pages](/authenticate/custom-configurations/custom-authentication-pages/) to control the layout and sizing directly.

</Aside>


## Make the logo clickable

1. Go to the Kinde dashboard > **Settings > Environment > Applications**.
2. Select **View details** on your target application tile.
3. Scroll down to the **Callback URLs** section.
4. Enter the destination URL in the **Application homepage URI** field (e.g., `https://app.yourbusiness.com` or `https://yourbusiness.com`).

    ![kinde application homepage URI](https://imagedelivery.net/skPPZTHzSlcslvHjesZQcQ/57b3c2a0-88ad-467d-48d5-39e0460e9300/socialsharingimage)

    Repeat for every application whose logo link you want to update.

If you are using [third-party tracking](/manage-users/view-activity/third-party-tracking/), the URL will also reflect that the user clicked out of the sign-up/sign-in screen, so you can distinguish this action from successful sign-ins.
